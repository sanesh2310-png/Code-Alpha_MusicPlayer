# CodeAlpha_MusicPlayer

A music player interface built with HTML, CSS, and JavaScript, styled as a turntable with a spinning vinyl record.

## Features
- Play, pause, next, and previous track controls
- Song title, artist, and duration display
- Live progress bar with seek support
- Volume control with mute toggle
- Interactive playlist — click any track to play it
- Autoplay toggle for continuous playback
- Keyboard shortcuts (Space to play/pause, arrow keys to skip tracks)

## Built with
- HTML
- CSS
- JavaScript
